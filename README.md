# Gravity Falls

Este projeto avaliativo foi desenvolvido na disciplina de Desenvolvimento Web I.

O site apresenta informações sobre a série Gravity Falls, abordando sua história, personagens, mistérios e algumas curiosidades.

## Tecnologias utilizadas

- HTML
- CSS
- Git
- GitHub
- GitHub Pages

## Organização do projeto

- `index.html` - estrutura e conteúdo do site
- `style.css` - estilização da página
- `imagens/` - imagens utilizadas no site

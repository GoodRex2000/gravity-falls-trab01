## 1. O que eu fiz

Para este trabalho eu escolhi criar um site sobre a série Gravity Falls. A ideia foi fazer uma página simples, com informações sobre a história, os personagens, a cidade e alguns elementos importantes da série.

Primeiro organizei o conteúdo que queria colocar no site. Depois criei o arquivo `index.html` e separei a página em partes usando elementos como `header`, `main`, `section`, `article` e `footer`. Em seguida criei o arquivo `style.css` para mudar cores, tamanhos, espaçamentos e a organização dos elementos.

Também coloquei as imagens em uma pasta chamada `imagens`, para deixar o projeto organizado. As ilustrações usadas no site são arquivos SVG simples feitos especialmente para esta página.

Depois de terminar os arquivos locais, o próximo passo é criar um repositório público no GitHub, enviar os arquivos usando Git e ativar o GitHub Pages para publicar o site.

## 2. Ferramentas usadas

Usei HTML para organizar o conteúdo da página e CSS para cuidar da aparência. Também usei o GitHub para guardar o código e o GitHub Pages para publicar o site na internet.

Para pesquisar as informações básicas da série, usei a página oficial da Disney sobre Gravity Falls.

## 3. O que eu aprendi

Com o trabalho eu entendi melhor a diferença entre HTML e CSS. O HTML é responsável pela estrutura e pelo conteúdo, enquanto o CSS muda a forma como esse conteúdo aparece na tela.

Também aprendi que um site estático pode funcionar apenas com HTML e CSS, sem precisar de JavaScript. Outra parte importante foi entender melhor como organizar pastas e arquivos para que os caminhos das imagens e da folha de estilo funcionem corretamente.

Na parte de Git e GitHub Pages, aprendi que o Git registra versões do projeto através de commits, enquanto o GitHub guarda o repositório online. O GitHub Pages consegue transformar os arquivos do repositório em um site público.

## 4. Publicação no GitHub Pages

Depois de criar o repositório, os passos usados para publicar são:

1. Adicionar os arquivos do projeto ao repositório.
2. Fazer commits com mensagens claras.
3. Enviar as alterações para o GitHub.
4. Abrir as configurações do repositório.
5. Ativar o GitHub Pages usando a branch principal.
6. Abrir o link gerado e testar em uma aba anônima.
